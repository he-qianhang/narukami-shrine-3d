# 鸣神大社 · 樱下巡游

非官方同人三维场景展示，灵感来自《原神》稻妻鸣神大社。

公开网页：<https://he-qianhang.github.io/narukami-shrine-3d/>

- 自动循环巡游，6段镜头共48秒；拖拽即可接管，闲置9秒后恢复。
- 触屏双指缩放；右上角“操作”可暂停、继续或复位。
- “操作 → 加载信息”显示本次模型读取量、下载／解压和模型准备时间，供排查首开慢；数据仅在当前页面内显示，不上传。它不包含脚本、背景加载或GPU首帧时间，读取也可能来自浏览器缓存。
- 右上角“全屏”切换全屏观看，并在浏览器允许时自动横屏。无法自动横屏时请横转手机；微信等内置浏览器可能不允许网页全屏。
- 电脑滚轮缩放，空格暂停或继续，R 复位。主动暂停后不会自动恢复。
- 尊重系统“减少动态效果”设置，默认暂停巡游和花瓣动画。

这是静态 Three.js 网页，无需登录。展示模型采用Meshopt精度压缩，全部1,770,634个三角面保留；gzip下载约12.7 MB，3张背景WebP合计约0.76 MB。没有浏览器内置gzip解压时下载约24 MB的压缩GLB，未支持WebAssembly的环境使用原始模型。数值精度和背景图片有轻微压缩损失，原始模型、背景与可编辑母版保留在制作工程中。手机性能和访问速度取决于设备、浏览器与网络，文件缩小不能保证所有地区网络一样快。

此仓库只包含网页运行文件，不包含Blender可编辑母版、原始参考或完整制作记录。原始未压缩GLB保留作为兼容加载资产。许可证在 `vendor/THREE-LICENSE.txt` 和 `vendor/MESHOPT-LICENSE.txt`。

本地预览：在仓库目录运行 `python3 -m http.server 4174 --bind 127.0.0.1`，打开 <http://127.0.0.1:4174/>。GitHub Pages从main分支根目录发布，`.nojekyll`保留。
